# Penguin Data Exploration

I explore species measurements in the Palmer Penguins dataset with plots and statistical tests.

## Run

Use a Python virtual environment. Install `pip install -r requirements.txt`, launch `jupyter notebook`, and open `penguin-analysis.ipynb`. Run cells from top to bottom. The notebook loads data through palmerpenguins.

## Scope and limitations

Exploratory analysis using ANOVA and contingency tests. Interpretation depends on assumptions, missing values and selected groups; this is not a published research result.
